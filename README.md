# BOLT
Параметрическая 3D-модель болта М12×50 по ГОСТ 7798-70 с возможностью изменения размеров через переменные. Модель включает шестигранную головку (S=19 мм, H=7.5 мм), стержень диаметром 12 мм и длиной 50 мм, полную резьбу (шаг 1.75 мм, длина 30 мм), скругление R=1 мм и фаску 1.6×45°.
